## 1. 育成（ステータスごとの EXP と 5つの成長フェーズ）

### 1-1. EXP
- **能力ごとに EXP（0〜1000）を持つ。1000 に達したら能力 +1、EXP は 0 に戻る。**
- 対象の能力
  - 野手：ミート（対左／対右）・パワー・選球眼・チャンス・走力・肩力・送球・捕球・9ポジションの守備適性
  - 投手：球速・球威・制球・スタミナ・ピンチ・各球種の変化量／キレ／重さ
  - 共通：体力の最大値・回復力（伸び幅は小さめ）
  - 二刀流・野手登板のため、野手も投手能力の EXP を、投手も野手能力の EXP を持つ
- 衰えは **マイナスの EXP** で表す。0 を下回ったら能力 −1、EXP は 999 から再開する。
- 隠し能力として **潜在能力**（能力ごとの上限）を持つ。上限に達した能力は EXP が入らない。

### 1-2. EXP の入り方
1日あたりの獲得量 ＝（試合経験＋練習＋キャンプ）× フェーズ倍率 × コーチ倍率 × モチベーション倍率（0.8〜1.2）

| 入手元 | 内容 |
|---|---|
| 試合経験 | 打席数・投球回・守備イニングに応じて、使った能力に入る（例：打席→ミート・選球眼、盗塁→走力、登板→制球・スタミナ） |
| 2軍の試合 | **実装済み**。1軍と同じ日程・同じ対戦チームの2軍と、同じ試合エンジンで試合する。出場した選手に経験が入る（1軍の65%として数える） |
| 練習指示 | 毎日、指示した系統に入る（既存の `practiceInstruction` を使う） |
| 春季キャンプ（1月1日〜31日） | 練習の効果 ×2。キャンプのメニューを選べるようにする（実装済み：効果×2のみ） |
| 秋季キャンプ（11月） | 若手のみ参加、効果 ×1.5 |

### 1-3. 5つの成長フェーズ
早熟・普通・晩成は **全盛期がいつ来るか** を決める。全盛期はおよそ5年。

| フェーズ | 早熟 | 普通 | 晩成 | EXP の入り方 | 衰え |
|---|---|---|---|---|---|
| 育成期 | 〜20歳 | 〜24歳 | 〜28歳 | ×1.2（ただし出場機会が少ない） | なし |
| 成長期 | 21〜22 | 25〜26 | 29〜30 | ×1.5 | なし |
| 全盛期（約5年） | 23〜27 | 27〜31 | 31〜35 | ×0.8 | なし |
| 過渡期 | 28〜30 | 32〜34 | 36〜38 | ×0.4 | 球速・走力・肩力が少し落ちる |
| 衰退期 | 31〜 | 35〜 | 39〜 | ×0.2 | 全体が落ちる。ミート・選球眼・制球は遅めに落ちる |

- 選手ごとに ±1年の個人差を付ける。全盛期の長さは4〜6年。
- 目安：成長期の主力が1年で主要能力 +3〜+8。衰退期は1年で −2〜−5。
- **毎シーズン終了後に、リーグ全体の能力平均と得点・打率を記録する。** 年々上がり続けていないか（インフレ）を確認するため。多少の変動は許容する。

## 2. コーチ・スカウト

### 2-1. 役職
- 1軍：ヘッド・打撃・投手・守備走塁・バッテリー・一塁コーチ・三塁コーチ
- 2軍：監督・打撃・投手・守備走塁
- スカウト（複数人）、経営コンサルタント（4章）

### 2-2. 能力（コーチ・スカウトは全員がすべての指標を持つ）
- 指導力：打撃指導・守備指導・走塁指導・球速球威指導・制球指導・スタミナ指導・変化球指導
- 人間性：人望
- 判断力：代打判断・継投判断・守備交代判断・走塁判断（ランナーコーチ）
- スカウト眼力
- 年俸は能力から自動算出する（選手と同じ考え方）

### 2-3. タイプ（相性）
選手にもコーチにも、能力の傾向から自動でタイプを1つ付ける。コーチのタイプは現役時代のタイプを引き継ぐ。

| 野手のタイプ | 主な能力 |
|---|---|
| 打撃職人型 | ミート・選球眼・チャンス |
| スラッガー型 | ミート・パワー |
| 俊足巧打型 | ミート・走力・守備適性 |
| 守備職人型 | 守備適性・送球・捕球 |
| 素材型 | パワー・走力・肩力 |
| 万能型 | 全体のバランス |

| 投手のタイプ | 主な能力 |
|---|---|
| 本格派 | 全体のバランス |
| 技巧派 | 制球・変化球 |
| 剛腕派 | 球速・球威 |
| イニングイーター | 球速・スタミナ |

- 判定方法：能力を平均との差で並べ、上位の組み合わせが最も合うタイプにする。どれも突出していなければ「万能型」「本格派」にする。
- 相性の係数
  - 同じタイプ：×1.2
  - 近いタイプ（例：打撃職人型と俊足巧打型）：×1.05
  - 遠いタイプ（例：守備職人型とスラッガー型）：×0.9
- **練習効果の倍率 ＝（指導力÷50）× 相性 × 人望の補正（0.85〜1.15）**
  - 相性と人望が極端に悪いと、倍率が 1 を下回ることもある（下限 0.6）

## 3. OB と記録

### 3-1. 記録の保存（これからの試合は全部残す）
- 選手ごと：年度別の成績（1軍・2軍）、通算成績、タイトル、表彰
- 球団ごと：年度別の順位・勝敗、ポストシーズンの結果
- 試合ごと：スコア、ボックススコア、一球ごとのデータ
  - 投球位置・球種・球速・結果・打球も保存し、過去の試合をアニメで再生できるようにする
- **今は記録していない項目を新しく追加する**
  - 二塁打・三塁打（OPS の計算に必要）
  - 守備：ポジション別の出場試合・守備イニング・刺殺・補殺・失策・併殺
  - 投手：球数・被安打・被本塁打・ホールドポイント

### 3-2. 開始時点の通算成績
- 固有12：すでにプロ年数が長い選手には、**通算成績だけを入力する**（年度別の内訳は不要）。初期選手編集に入力欄を追加する。
- 新規チーム：能力とプロ年数から、それらしい通算成績をランダムに作る。

### 3-3. OB
- 引退した選手はすべて OB 一覧に移る。他球団の OB も含む。
- 開始時点で、架空の OB を **野手30人・投手30人ほど** 用意する（通算成績・タイプつき）。
- **OB の指導力 ＝ 50% は通算成績から予想される値 ＋ 50% は隠れた値**
  - 期待外れ・期待以上の名コーチもあり得る
  - 獲得する前は、幅でしか分からない。例：2000本安打のミート型 OB → 打撃指導力は「B〜S」と表示
  - 雇って1シーズン経つと本当の値が分かる
- 打診のしかた：OB は自分の古巣を優先する。他球団の OB を呼ぶには、同じ条件では断られるので年俸を上乗せする（目安 ×1.3）。
- CPU 球団の監督・コーチも、この OB から選ばれる（11章）。

## 4. 球団経営

### 4-1. お金の流れ（1シーズン）
- 収入
  - 観客動員 × 客単価（勝率・人気選手・順位争いで増減。球場の収容人数が上限）
  - 放映権
  - グッズ（選手グッズ・記念グッズ。企画の当たり外れあり）
  - スポンサー（地元企業・大企業の一覧から募集。条件つきの契約もある：Aクラスでボーナス など）
  - ポストシーズンの収入
- 支出：選手の年俸・コーチの年俸・契約金・運営費・補強費（外国人の獲得費用、トレードの金銭）

### 4-2. 経営コンサルタント
- 雇うと経営をおまかせにできる。結果はコンサルタントの手腕しだい。年俸がかかる。
- CPU 球団の経営は、その球団が雇っているコンサルタントの手腕で決まる。

### 4-3. オーナー評価と解任
- オーナー満足度（0〜100）を毎月・毎シーズン更新する。
  - 成績：順位・優勝・ポストシーズン・前年からの伸び
  - 経営：収支・観客動員・スポンサー数
  - 経営がうまければ、6位でも解任されにくい
- 満足度が低いまま一定期間続くと、**解任** される
  - 例：シーズン終了時に 20 未満、または 2年連続で 35 未満
- 解任されたときにどうなるかは未定（決めたい点を参照）

## 5. ドラフト・スカウト・育成選手

### 5-1. スカウト
- 毎年11月1日に、翌年のドラフト候補（高校・大学・社会人・独立リーグ）を生成する。
- スカウトが毎週1回、調査結果を報告しに来る。
  - **今の能力**：実際の値の ±5 の幅で分かる
  - **潜在能力**：スカウト眼力が高いほど正確に分かる。低いと「不明」や外れた評価になる
- ドラフトの時点で潜在能力は決まっている。ただし入団後にその通りに伸びるかは、**50%：予想通り／25%：期待外れ／25%：期待以上**。

### 5-2. ドラフト会議（毎年10月の最終日）
- 1位は全球団が同時に入札する。重複したら **抽選**。外れた球団は再入札する（外れ1位）。
- 2位以降は、順位の逆順でウェーバー方式（NPB と同じく、リーグを交互にする）。
- **契約金あり**：1位は最高1億円＋出来高5000万円、それ以下は順位に応じて減る。新人の年俸も上限つき。
- 本指名のあとに **育成ドラフト** を行う。

### 5-3. 育成選手
- 支配下（背番号2桁以下）は最大70人。育成選手は3桁の背番号。
- 育成選手は2軍の試合には出られるが、1軍には出られない。7月末までに支配下登録すれば1軍に上がれる。
- 育成契約は3年。過ぎたら自由契約か、育成で再契約。
- 次の契約もできる
  - 戦力外にした選手を育成で再契約する
  - トライアウトに参加した選手と育成契約する
  - 育成ドラフト
  - 外国人選手と育成契約する
  - 育成選手同士のトレード

## 6. FA・トレード・戦力外・外国人選手

### 6-1. FA
- FA権の取り方は0章のとおり（6年。わざと NPB より短くしている）。
- 年俸ランクによる補償
  - A：球団内の年俸1〜3位、B：4〜10位、C：11位以下
  - A・B の選手を FA で獲った球団は、元の球団に **人的補償（プロテクト外の選手1人）＋金銭** か、**金銭のみ** を払う。どちらにするかは元の球団が選ぶ
- FA 選手は年俸が高くなりやすい（市場価値 ×1.2〜1.5）。

### 6-2. トレード
- 最大3人対3人＋金銭まで。
- **トレード期限は7月31日**。オフシーズンは再開する。
- CPU は「戦力の釣り合い」と「チームに足りないポジション」で受けるかどうかを判断する。

### 6-3. 戦力外・トライアウト
- 10月から戦力外通告。11月にトライアウトを行う。
- 戦力外の選手は、実力より年俸が安くなりやすい（×0.6〜0.8）。

### 6-4. 外国人選手
- 毎オフ、海外の選手の一覧（能力・希望年俸）が届く。シーズン中も補強できる。
- 1軍の外国人は最大4人（既存のルール）。

## 7. オフシーズン処理（日付の流れ）

| 時期 | 内容 |
|---|---|
| 10月上旬 | 公式戦終了 → クライマックスシリーズ |
| 10月中旬〜下旬 | 日本シリーズ |
| 10月31日 | ドラフト会議（本指名・育成） |
| 10月〜11月 | 戦力外通告 → 引退 → トライアウト |
| 11月 | 表彰（タイトル・MVP・ベストナイン・ゴールデングラブなど）、秋季キャンプ |
| 11月 | FA宣言 → 交渉 → 補償 |
| 11月〜12月 | 契約更改（年俸の増減。大幅な減額を拒否すると自由契約） |
| 12月 | コーチ人事、CPU 球団の監督の交代、外国人選手の獲得、トレード |
| 1月1日 | 年度更新：年齢＋1、プロ年数＋1、成長フェーズの判定、新しい日程の生成（実装済み） |
| 1月1日〜31日 | 春季キャンプ（練習の効果 ×2。実装済み） |
| 2月 | オープン戦 → 開幕 |

- **監督就任は、1年目のドラフト会議の日から。** 2026年開始なら、2025年10月31日から始まる（実装済み。ドラフトの中身はフェーズ4）。

- 実装済みの流れ：シーズン終了 →「シーズンを終える」で記録を確定 → 10/31（ドラフトの日）→ 1/1（年度更新）→ キャンプ → オープン戦。

- 実装の前に、**156試合の公式戦が10月上旬までに終わるか日程を確かめる**。終わらない場合は、開幕日か交流戦の位置を調整する。

## 8. タイトル・表彰

### 8-1. 毎年表彰する項目（NPB が実際に表彰しているもの）
- 打撃：首位打者・本塁打王・打点王・盗塁王・最高出塁率・最多安打
- 投手：最優秀防御率・最多勝利・最多奪三振・最高勝率・最多セーブ・最優秀中継ぎ（ホールドポイント）
  - 最高勝率の資格は「13勝以上」を156試合に換算して **14勝以上**
- 年間：MVP（各リーグ）・最優秀新人（新人王）・ベストナイン・ゴールデングラブ・沢村賞・カムバック賞
- 月間 MVP（投手・野手）
- 試合ごと：日本シリーズ MVP／優秀選手、オールスター MVP、CS の MVP
- 打率・防御率・最高出塁率の資格は、規定打席（484）・規定投球回（156）

### 8-2. ベストナイン・ゴールデングラブの決め方（提案）
実際の NPB は記者の投票で決まる。ゲームでは **「点数で候補を出し、記者300人の投票を再現する」** 方式にする。

1. **資格**
   - そのポジションで試合数の半分（78試合）以上守った野手
   - 投手は規定投球回以上、または50試合以上登板
   - DH はそのリーグで DH として78試合以上
2. **点数**
   - ベストナイン：攻撃の貢献度（打率・出塁率・長打率・本塁打・打点・盗塁から作る指標）に、ポジションによる補正を加える（捕手・遊撃は守備の負担が大きいので加点）。投手は防御率・勝利・投球回・奪三振。
   - ゴールデングラブ：エンジンの守備データから作る「守備で防いだ点」を使う
     - 打球ごとに「その打球が捕れる確率」が分かる
     - 難しい打球を捕ったら加点、捕れるはずの打球を逃したら減点
     - これに失策・補殺・併殺を加える。捕手は盗塁阻止率とバッテリーの防御率
3. **投票の再現**
   - 記者ごとに点数へ少しの揺らぎを加えて1位を選び、得票数を出す
   - 揺らぎの中身：人気、チームの順位、前年に受賞したかどうか（実際にもある「連続受賞されやすさ」）
   - 結果は「得票数つき」で発表する。僅差だと驚きの受賞もあり得て、現実らしくなる

## 9. データの保存方法

### 9-1. おすすめ：SQLite（`drift` パッケージ）
今の SharedPreferences（ブラウザの保存領域）は容量の上限が約5MB。何年分もの記録や一球ごとのデータは収まらない。

| 方法 | Windows | Android | iOS | Web（今の確認用） | 向いていること |
|---|---|---|---|---|---|
| **drift（SQLite）** | ○ | ○ | ○ | ○（追加の設定が必要） | 年度別・通算の集計、ランキングの検索が速い。記録を大量に残すのに向く |
| hive_ce | ○ | ○ | ○ | ○ | 簡単だが、集計や検索は自分で書く必要がある |
| sembast | ○ | ○ | ○ | ○ | 簡単。データが大きくなると遅い |

- 記録を何年分も溜めて集計する用途には **drift** が最適。
- 加えて、**セーブデータのファイル書き出し・読み込み**（JSON）を用意する。バックアップや、パソコンとスマホの間の移動に使う。

### 9-2. ご自身でやっていただくこと
パッケージの追加やコードの書き換えは、こちらで行う。お願いしたいのは、端末向けにビルドするための準備だけ。**当面は「Windows（Web版）」と「Android（Galaxy S25の実機）」だけを対象にする。**

1. **Windows（Web版）**：準備は不要。Chrome があればよい。Windows アプリ版は後回し（Visual Studio は要らない）。
2. **Android（Galaxy S25 の実機）**
   - Android Studio を入れ、初回起動で Android SDK を入れる。
   - Android Studio の「SDK Manager → SDK Tools」で **Android SDK Command-line Tools** にチェックを入れて入れる。
   - ターミナルで `flutter doctor --android-licenses` を実行し、すべて `y` で承諾する。
   - S25 側：設定 → 端末情報 → ソフトウェア情報 →「ビルド番号」を7回タップして開発者向けオプションを出し、「USBデバッグ」をオンにする。USB でつなぎ、画面に出る「このパソコンを許可」を許可する。
   - `flutter devices` に S25 が出れば準備完了。
3. **iPhone**：**PWA**（Webアプリをホーム画面に追加）で遊べるようにする。Mac も Apple の有料登録も不要。

## 11. CPU 球団
- 各 CPU 球団の監督は OB からランダムに選ばれる。監督にも能力と傾向を持たせる。
  - 傾向：バントを多く使う／強攻、継投が早い／遅い、若手を起用する、守備を重視する など
  - 手腕：オーダーの組み方や采配の上手さ。高いほど最適に近い判断をする
- 成績が悪ければオフに監督が交代する。
- 補強（ドラフト・FA・トレード・外国人）は、チームに足りないポジションと予算を見て CPU が判断する。
- 経営は、球団が雇っている経営コンサルタントの手腕で決まる。

## 12. ポストシーズン・オールスター

- **クライマックスシリーズ**（各リーグの上位3球団）
  - ファーストステージ：2位 対 3位、3試合制、全試合2位の本拠地で行い、先に2勝した方が勝ち上がる
  - ファイナルステージ：1位 対 勝ち上がった球団、6試合制で先に4勝した方が勝ち。1位に1勝のアドバンテージ
- **日本シリーズ**：7試合制（先に4勝）。本拠地は 2-3-2 の順。DH は本拠地のリーグのルールに従う（今のゲームの DH 設定に合わせる）
- **オールスター**：2試合
  - 出場選手はファン投票（人気と成績から再現）・選手間投票・監督推薦で選ぶ
  - 今の日程にあるオールスターは仮のチーム（PL_ALLSTAR など）なので、実際の選手で試合をする形に作り直す
- 156試合制は変えない。
