# 球種カタログ（たたき台 2026-10-07）

## 約束ごと
- 角度（右投手の場合。左投手は左右反転）：0＝利き腕側（シュート方向）、90＝真下、180＝グラブ側（スライダー方向）
- 球速差：その投手のストレートとの差（km/h）
- 変化量：0〜100
- 球速と変化量の関係：同じ球種なら、球速が速いほど変化量は小さい
  - 変化量 ＝ 上限 −（上限−下限）× 速さの位置 ± 5
  - 速さの位置は、球速差の範囲の中で 0（いちばん遅い）〜1（いちばん速い）
- キレ・重さ：表の幅の中で決める
  - キレは制球と変化球のセンス、重さは球威に寄せる
  - 決め球の1球だけは +5〜10
- 珍しさ（選ばれる重み）：普＝10、やや珍＝4、珍＝2、レア＝0.5
- 球種の数：先発は4〜8、中継ぎ・抑えは3〜5
  - ストレートは必ず入る
  - 同じ系統からは原則2つまで
- 投球割合：ストレート系が合計35〜55%、残りを重みで分ける
- 投打のバランスは、実装後に growth_test で調整する
