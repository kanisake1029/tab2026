# 打者の対応モデル 仕様書（案）2026-11-09

打者が投球1球ごとに「何を待ち、どれだけ合わせられたか」を決める計算。
結果は スイングの空振り／ファウル／打球（速さ・角度・向き）になり、その後は今までどおり物理で飛ぶ。
対象：`lib/engine/swing_model.dart`（SwingModel.swing）と、`match_simulator.dart` の `_swingRead`・能力の補正。

## 0. 今の作りと足りないところ

| 要素 | 今 | 足りないところ |
|---|---|---|
| 球種ごとの球速 | 変化球は全部の平均の速さで待つ | スローカーブもシュートも同じ速さ扱い |
| 前の球との球速差 | 打者の計算では使っていない | 緩急が効かない |
| 待ち方 | 球種の割合どおりに直球を待つ | 直球が少ない投手は、いつも変化球を待たれる（松村の三振率8%の原因の1つ） |
| 変化量 | 大きいほど合わせきれない（空振り↑） | 小さい変化（シュート・カットなど）で芯を外す効果がない |
| 重さ | 打球の反発が下がる（飛距離↓） | このまま使う |
| キレ | 曲がり始めが遅い・見誤りやすい | 芯を外す効果（凡打↑）が弱い |
| 打者の能力 | ミート・パワー・選球眼・弾道を使う | このまま使い、効き方を整理する |
| チャンス・ピンチ | 得点圏で ±(値−60)/5 を ミート・パワー・選球眼／制球・キレに足す | 投手の球速・球威に効かない |

## 1. 待ち球を決める（球ごと）

1. 打者は、投手の持ち球から「待つ球」を1つ選ぶ。
   - 選ぶ重み ＝ 球種の割合。ただし直球系は「警戒の分」を上乗せする。
   - 直球を待つ確率 ＝ 0.35 ＋ 0.65 × 直球系の割合（直球が21%でも約49%は直球を警戒）。
   - カウント：打者有利は直球、追い込まれると変化球にも備えるので幅を広げる（今の ±0.06 を引き継ぐ）。
   - 作戦「直球狙い」「変化球狙い」は今と同じ。
2. 待つ球の速さ・曲がりで振り出す。来た球が待ち球と違うほどずれる。
   - **速さの差**：待ち球と来た球の球速差の分だけタイミングがずれる。スローカーブ107km と チェンジアップ129km は別物になる。
   - **曲がりの差**：待ち球と来た球の変化（向き×大きさ）の差の分だけ、高さ・内外のずれになる。
3. 見極め（途中で直す）：選球眼・ミートが高いほど、ずれを多く直せる。キレがあるほど直す時間が短い（§3）。

## 2. 前の球との球速差（緩急）

- 打者の体内時計は、直前の球の速さに引っ張られる。
  - 待ち球の速さ ← 待ち球の速さ ＋ (前の球の速さ − 待ち球の速さ) × 引き込み
  - 引き込み ＝ 0.25 ×（1 − (ミート−60)×0.01）、0.1〜0.4。打席の初球は前の打席の最後の球を使わない（0）。
- 例：前が148kmの直球、次が107kmのスローカーブ → 大きく前に崩れる（空振り・泳いだ凡打）。同じ球が続くと合わせやすい。

## 3. 球種の性質の効き方

| 性質 | 効き方 | 結果 |
|---|---|---|
| 球速 | 振り遅れ（今の指数の効き）＋ 緩急（§2） | 空振り↑ |
| 変化量 小（〜35） | 打者は合わせやすい（空振り↓）。ただし芯の少し外に当たる：芯ずれを 変化量に応じて足す（小さい変化ほど「当たるが芯を外す」割合が大きい） | 凡打（ゴロ・詰まり）↑ |
| 変化量 大（60〜） | 読めても合わせきれない分が大きい（今の resid） | 空振り↑。当たれば芯ずれは小さめ → 凡打↓（打たれると強い） |
| 重さ | 打球の反発が下がる（今の heavyCor ＋ 球威への換算） | 飛距離↓・長打↓ |
| キレ | 曲がり始めが遅い → 見極めの時間が短い（今の tLate）。見誤りも増える。芯ずれにも少し足す | 空振り↑・凡打↑ |

- 変化量の「小さい＝凡打」「大きい＝空振り」は、1本の曲線で入れる：
  - 空振りへの効き ∝ 変化量（大きいほど強い）
  - 芯ずれへの効き ∝ 変化量 ×（1 − 変化量/100）の山形（30〜50 で最大）
- 直球系（ストレート・ツーシーム・カット・スプリットファスト）も同じ式に入れる。ツーシーム・カットは「小さい変化」として凡打を生む。

## 4. 打者の能力

| 能力 | 効き方 |
|---|---|
| ミート | タイミングのばらつき・芯ずれのばらつきが小さい。ずれを直せる量（§1-3）、緩急の引き込み（§2）が小さい |
| パワー | スイングの速さ → 打球の速さ・飛距離 |
| 弾道 | 狙う打球角度（バットの入る角度と、ボールのどこを叩くか） |
| 選球眼 | 球種の見誤りが少ない。ボール球を振らない（今のスイング判断）。曲がりの見極め（track） |

能力の低い側をゆるめる `soften` はそのまま。

## 5. チャンス・ピンチ

- 場面：得点圏に走者（今と同じ）。7回以降で1点差以内・同点なら効きを1.5倍。
- 打者（チャンス）：ミート・パワーに ±(チャンス−60)/5。選球眼には /10。
- 投手（ピンチ）：制球・キレに ±(ピンチ−60)/5、球威に /5、球速に ±(ピンチ−60)/10 km。
  - 例：ピンチ80 → 制球+4・キレ+4・球威+4・球速+2km。ピンチ40 → それぞれ −4・−2km。

## 6. 対象外：走力と守備（④）

内野安打・ゲッツー崩れ・進塁は、打球が決まった後の「守備と走塁」で決まるので、このモデルには入れない（今の守備の計算のまま）。
ただし §3 でゴロが増える投手（小さい変化・重い球）は、走力と守備の勝負の場面が増え、ゲッツーも増える。間接的にはつながる。

## 8. 追記 2026-11-10：能力の基準合わせ・チャンス／ピンチの作り直し

- **基準合わせ**（`MatchSimulator.levelCenter`）：打席ごとに、打者の水準（ミート・パワー・選球眼の平均）と投手の水準（球速の能力値・球威・制球の平均）の中間が 60 になるよう、両方を同じだけずらして計算する。
  - 能力の差はそのまま残る。同じ数字どうしなら 30 対 30 も 90 対 90 も 60 対 60 と同じ結果（打率 .234〜.262・三振 15〜21%・四球 約8%）。
  - 投手側は、制球・キレ・変化量・重さ・球威、打者が受ける球の速さと曲がり幅をずらす。表示・記録の球速は本当の値。
  - 守備と走塁は合わせない（野手の処理の速さ と 走者の速さ の勝負。能力ごとの動作の秒数で決める）。
- **チャンス**：得点圏で、打者の能力（ミート・パワー・選球眼）がまとめて (チャンス−60)×0.36 上がる。90 で得点圏打率 約+.04、30 で 約−.03。
- **ピンチ**：得点圏で、投手の能力（球速・球威・制球・キレ・変化量・重さ）がまとめて (ピンチ−60)×0.23 上がる。90 で被打率 約−.05、30 で 約+.065。
- 7回以降の1点差以内・同点は どちらも1.5倍（§5 のまま）。
- 見誤り（notIdBase）は 0.65 に。

## 9. 追記 2026-11-11：タイトルの水準（本塁打・打点）の合わせ

- 守備の基準値（走力・反応・送球）は実際のプロの数値に合わせた定数なので動かさない。打撃側で合わせる。
- 1シーズン通しで、調整前は 首位打者 .317・本塁打王 76・打点王 163。本塁打が多すぎた。
- 原因：ミートが高い弾道4 の打者は、当たりのばらつきが小さく、打球が本塁打の角度に集中する（ミート80→89 で本塁打がほぼ倍）。
- 直し：
  - 弾道1つあたりのスイング角度の差 `Spec.attK` 3 → 1.8（高い弾道が本塁打に偏りすぎない。フライの一部がライナーになる）
  - パワー → スイングの速さの傾き `Spec.batB` 0.21 → 0.12（パワー60 の速さは同じ。`batA` 103.8）
  - 打者が上回るときの能力差の効き `levelGain` 1.07 → 1.0
  - 見誤り `notIdBase` 0.65 → 0.69（三振率を 18% 台に）
- 結果（notIdBase 0.65 のときの1シーズン）：首位打者 .374（2位 .334）・本塁打王 60（2位 43）・打点王 136、リーグ打率 .254・得点 4.19。
  - 実力値（多くの試合の平均）：最強打者（右投手にミート89・パワー89・弾道4）で 打率 .34〜.35、1シーズン 約55本・約130打点。パワー89・ミート75前後の主砲は 約35本。
- 弾道1 はパワー90でも本塁打が少ない（600打席あたり 約8本）のは狙いどおり。
