# アマチュア球界とスカウト網（設計書・2026-11-03）

## 0. 考え方
- 今は「その年の候補 180人（本指名120・育成60）」をいきなり作っている。これをやめる。
- 代わりに、高校・大学・社会人・独立の**チームが1年中ある世界**を作る。
- 選手は前もって作らない。**12球団のスカウトが「発掘」したときに、その学校・チームの選手として生まれる**（中の処理では発掘＝生成）。
  - 人数は決めない。スカウトの数×眼力と、学校の強さで、発掘される人数が決まる。
- **12球団のどこかが発掘した選手が「プロ志望」＝ドラフト候補**になる。
  - 自球団が調査していない選手は、自球団からは「不明」（名前も能力も分からない）。CPU 球団から見ても同じ。
- 候補は**支配下・育成で分けない**（1つの一覧）。各球団が評価を見て、支配下で指名するか育成で指名するかを決める。
- スカウトを多く雇うほど・眼力が高いほど、発掘が増え、見立ても正確になる。スカウトには年俸がかかる。

## 1. 高校（3,400校）
- 47都道府県に人口の比で校数を割り振る（例：東京 約250・大阪 約170・鳥取 約25）。
- 学校ごとに持つもの：名前・都道府県・強さ（1〜99。私学強豪がわずかにいる山型）・名門度（強さの毎年の変わりにくさ）。
- 部員は作らない。有望株は発掘されたときだけ生まれる（2. の発掘）。
  - **発掘は3年生だけ**（その年のドラフトの学年）。1〜2年生は発掘されない。
- 大会（3,400校すべて。試合をして、今年の大会は画面に出す）：
  - **春**：都道府県大会（4〜5月）→ 春の甲子園（50校）
  - **夏**：都道府県大会（7月）→ 夏の甲子園（8月・50校）
  - **秋**：都道府県大会（9〜10月）→ 9地区大会（北海道・東北・関東・中部・北陸・東海・近畿・中国＋四国・九州＋沖縄）
  - 甲子園は各都道府県1校、北海道・東京・大阪は2校（計50校）。50校の中からランダムに14校がシード（1回戦なし）。
  - 試合は他リーグと同じく1打席ずつの簡易試合で行う。発掘済みの選手はその力で、ほかの部員は学校の強さに合った力の「無名の選手」として出る。
  - 発掘済みの選手には試合ごとに打撃・投球成績が付く（アマ時代の成績に残る）。

## 2. 大学（54校）
- 9地区に6大学ずつのリーグ。各大学 **50試合**（4〜10月。総当たりを10回）。
- 高校と同じく、選手は発掘されたときに生まれる。**発掘は4年生だけ**（その年のドラフトの学年）。
- 高校で指名されなかった発掘済みの選手は、大学・社会人・独立に進む（または引退）。大学に進んだ選手は、そのまま大学の選手として続く。

## 3. 社会人・独立
- 社会人：企業チームを持つ。選手は発掘で生まれる。高校・大学から入る選手もいる。
- **都市対抗**：地区の予選（6月）→ 本大会（7月・トーナメント）。チーム数・出場枠は段階2で決める。
- 独立：今ある他リーグ（独立リーグ）の選手から（今の仕組みのまま）。

## 4. 過去の記録（表示はしない）
- 今年の大会・リーグは画面に出す（7.）。**過去の年度・過去の大会**は画面に出さず、各チームに独立リーグのチームと同じように残す：
  - 年ごとの戦績（大会の成績・リーグの順位と勝敗）
  - ドラフト指名実績（年・球団・順位・選手）
- 画面には出さないが、パイプ（5.）や、今後の機能（例：名門の評判）に使える。

## 5. スカウト網と発掘
- **チーフスカウト 1〜3人**（見立ての正確さ。複数いると眼力の高い人を中心に合わせる）＋ **地区担当スカウト 0〜18人**（1地区に最大2人）。
- スカウトは年俸がかかる（目安：1人 1,000〜2,500万。眼力が高いほど高い）。フロントで雇う・外す・地区を変える。
- 毎週、地区担当は受け持ちの地区の学校を**強豪校から順に**回る：
  - **発掘**：その学校で原石を見つける（＝選手が生まれる）。見つかる確率は、スカウトの眼力×学校の強さ×パイプ。
    - 強豪校ほど見つかりやすく、1校から見つかる人数も多い。
    - 弱い学校にもまれに逸材がいるが、眼力が高くないと見つからない。
    - 発掘で生まれる選手の力は、学校の強さが高いほど高めに出る（弱い学校の逸材は、まれに大きく外れる）。
  - **調査**：自球団が発掘・調査した選手の調査回数を増やし、能力・才能・向上心の幅を狭める（今の仕組み）。
  - 他球団が発掘した選手を、自球団のスカウトがあとから見つけることもある（すでに生まれている選手を「知る」）。
- 1地区に2人置くと、その地区で回れる学校が増える（2人目は1人目より効果が少し小さい）。
- 担当のいない地区でも、甲子園で活躍した選手は自然に分かる（少ない人数）。
- **注目**にした選手は優先して調べる。
- **パイプ**：ある学校・チームから選手を指名すると、その学校・チームとのパイプができる。パイプがあると、そこで原石を発掘しやすくなる（指名するたびに強まり、年とともに少しずつ弱まる）。
- CPU 球団も同じ仕組みで発掘・調査する（人数・眼力は球団ごと。計算は簡略にする）。

### 海外スカウト
- 他リーグ（MLB・3A・2A・1A・KBO・CPBL・メキシカン・中東・豪州・米独立・日本独立）ごとに、**海外担当スカウトを最大2人**置ける。年俸がかかる。
- 海外担当は受け持ちのリーグの球団を回り、選手を発掘・調査する（他リーグの選手はもう世界にいるので、発掘＝「知る」）。
- **一度発掘した海外の選手は、候補として追い続けられる**（年をまたいでも、移籍してもリストに残る。引退・NPB 入りで外れる）。調べるほど見立てが正確になり、成績の移り変わりも見られる。
- 外国人の獲得の候補は、今の「その年の一覧」から、自球団の海外スカウトが発掘した選手の一覧に変える。
- 日本独立リーグの選手も、この海外担当（日本独立）が発掘するとドラフト候補になる。

## 6. ドラフト
- 候補＝12球団のどこかが発掘した、その年の卒業学年の選手（独立・社会人は年齢の条件で）。
- 自球団の候補一覧に名前が出るのは、自球団が調査した選手だけ。調査していない選手は指名できない。
- 自球団が調査していない選手が他球団に指名されると、ビジョンで初めて名前を知る。
- 支配下・育成は分けない。どの選手も支配下でも育成でも指名できる（CPU も評価で決める）。
- 指名されると、その学校・チームの指名実績に残り、パイプが強まる。

  - 大学：9地区のリーグの順位表。都市対抗の結果。
  - 学校を開くと、今年の試合の結果と、その学校の選手（自球団が調査した選手だけ名前が出る）。過去の戦績・指名実績は出さない。
- スカウト画面：チーフ・地区担当と受け持ち地区、今週の発掘・調査の報告。
- 志望届の「アマ時代の成績」に、大会ごとの成績（例：2025夏 甲子園 ベスト8 打率.412 2本）が入る。

2. 高校の大会（春・夏・秋）・大学リーグ・都市対抗の結果と成績。

4. 画面（アマチュア画面・スカウト画面の更新・志望届の成績）。
5. 何年か回して、候補の人数・質・ドラフトの結果が今と同じくらいになるか調べる。

## 実装メモ（段階3・2026-11-04）
- スカウトの役職：`チーフスカウト`（1〜3人）、`地区スカウト・<地区>`（1地区2人まで）、`海外スカウト・<リーグid>`（1リーグ2人まで）。年俸は眼力で 600万〜2,800万（`CoachEngine.scoutSalary`）。
- 以前の「スカウト」は本拠地の地区担当になる。全球団にふつうの顔ぶれ（地区担当5〜9地区・海外担当2〜4リーグ＋日本独立1）を1度だけ置く（kv `scoutNetV1`）。
- 発掘（`lib/engine/amateur_scout.dart`）：毎週月曜（4〜10月）。地区担当は1人目 3＋眼力/25 校、2人目は7割を、強い順（大学・社会人は先、パイプがあると先）に回る。
  - 隠れた原石の数＝ポアソン（高校 0.03＋3.2×(強さ/100)^3 など）。見つける確率＝0.32×(0.5＋眼力/100)×(1＋0.5×パイプ)。強さ45未満のチームは眼力が低いと見つけにくい。
  - 甲子園ベスト8のチームの選手は全球団が知る。
- 候補（Prospect）は `knownBy`（知っている球団）を持つ。空は以前の方式の候補（全球団が知る）。ドラフトは知っている候補だけ指名できる（CPU も）。
- 指名されるとパイプ＋1（毎年2割ずつ弱まる）と指名実績。
- 海外担当：毎週、受け持ちのリーグの球団を回る。海外の選手は自球団の `foreignWatch`（追い続ける）に、日本の独立リーグの選手は候補に（`AmWorld.indie` で翌年以降も追う）。外国人選手の画面は、追っている選手のうち12月1日の一覧に載った選手と、一覧の外の選手（声をかける）。
- 移行：今年のドラフトが以前の方式の候補なら、その年は発掘しない。ドラフト直前（10月）に候補が1人もいなければ、以前の方式で作る（はじめからのとき）。
