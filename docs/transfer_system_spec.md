# 移籍・ドラフト・育成制度 仕様書（設計確定版）

> 状態: **実装済み（2026-11-03）**。数値は「仮」と書いたものを除き決定値。実装で仮に決めた値は末尾の「実装メモ」。
> 目的: 移籍を活発にしつつ、戦力の公平性を保つ。ぜいたく税は**入れない**。
> 関連: `docs/player_growth_finance_spec.md`、`lib/engine/coach_engine.dart`、`lib/engine/growth_engine.dart`、`lib/engine/draft_engine.dart`、`lib/engine/transfer_engine.dart`、`lib/models/player.dart`

## 1. ドラフト

### 1.1 指名順
| 巡目 | 方式 |
|---|---|
| 本指名1位 | 重複したら**完全に均等な確率の抽選**（順位による重み付けなし） |
| **1.5位**（補償の巡） | 1位がすべて決まったあとに行う。**Aランク**の選手をFAで失った球団だけが指名する。重複は公平な抽選（2.3参照） |
| 本指名2位 | ウェーバー（最下位から） |
| **2.5位**（補償の巡） | 2位がすべて決まったあとに行う。**Bランク**の選手をFAで失った球団だけが指名する。重複は公平な抽選（2.3参照） |
| 本指名3位以降 | ウェーバー。**折り返し**（3位は最上位から、4位は最下位から、…） |
| 育成1位 | 最下位から |
| 育成2位以降 | 折り返し（2位は最上位から、3位は最下位から、…） |

### 1.2 志望届と希望球団
- 志望届を出すときに、希望球団を **1〜3まで設定する**か、**「希望なし」**（プロに入れればよい）を選ぶ。
- 希望球団は**志望届を出した時点で固定**する。その後の監督交代・トレードなどでは変わらない。
- 入団した球団による国内FA資格の短縮:

| 入団した球団 | 国内FA資格 |
|---|---|
| 1希望 | 短縮なし（8年） |
| 2希望・3希望 | 1年短縮（7年） |
| 上記以外 | 2年短縮（6年） |
| 「希望なし」を選んだ選手 | 短縮なし（8年） |

- 短縮するのは**国内FAだけ**。海外FA・ポスティングには影響しない。
- 「希望なし」の選手は、育てても早く出ていかないことが指名する側の利点になる。

### 1.3 希望球団の決まり方
球団ごとに次の7要素から点数を出し、上位を1〜3希望にする。

| 要素 | 内容 |
|---|---|
| 育成設備 | 球団の設備レベル |
| 監督との相性 | `CoachEngine.affinity(監督.type, 選手タイプ)` を使う |
| 憧れの選手 | 選手ごとに3人設定。その選手が所属する球団に加点 |
| チーム状況 | **自分のポジションの層の薄さ**（出場機会） |
| 資金力 | 球団の資金 |
| 強さ | 前年の順位・勝率 |
| 人気度 | 球団の人気 |

- **偏り対策**: 資金力・強さ・人気度・育成設備は強い球団ほど高くなりやすい。選手ごとに**志向タイプ**を持たせ、要素の重みを変える。

| 志向タイプ | 重く見る要素 |
|---|---|
| 出場機会重視 | チーム状況 |
| 優勝志向 | 強さ |
| 育成重視 | 育成設備・監督との相性 |
| 華やかさ志向 | 人気度・資金力 |

- タイプの割合は、希望がリーグ全体に散らばるように調整する（仮）。

## 2. 国内FA・補償

### 2.1 資格年数
- 国内FA: **8年**（いまの `Player.hasFA` は `faService >= 6`。**8に戻す**）。志望届による短縮は1.2のとおり。
- 外国人選手は外国人枠でなくなるまでFA対象外。ただし提携選手は2.4参照。

### 2.2 補償
- **短縮FA・通常FAにかかわらず**、移籍した選手の**年俸ランク**に応じて元の球団に補償を与える。
  - **補償の指名権**を**リーグが**与える。獲得した球団からは指名権を取らない。
  - **金銭補償**は獲得した球団が払う。

元の球団が、次のどちらかを**選ぶ**。金額は移籍した選手の**前年の年俸**に対する割合。

| 年俸ランク | 選択肢① 指名権＋金銭 | 選択肢② 金銭のみ |
|---|---|---|
| A | **1.5位**（1位と2位の間の指名権）＋年俸の**50%** | 年俸の**100%** |
| B | **2.5位**（2位と3位の間の指名権）＋年俸の**40%** | 年俸の**80%** |
| C | （指名権なし） | 年俸の**30%** |

**2回目以降のFA**
- 選択肢①は、指名権はそのままで、金銭が**半分**になる（A：1.5位＋25%、B：2.5位＋20%）。
- 選択肢②（金銭のみ）とCランクの扱いは未決（8章）。

- 呼び方は「**1.5位**」「**2.5位**」とする（画面表示・ログ・コード上の名前もこれに揃える）。
- 補償の指名権は**追加**でもらうもの。元の球団の1位・2位などの指名権はそのまま残り、獲得した球団も指名権を失わない。
- 1.5位・2.5位はドラフトの中で独立した巡として行う（1.1の表のとおり）。

### 2.3 1.5位・2.5位の指名方法
- **流出1人につき1枠**。上限は**ない**。
  - 例: Aランクの選手が同じ球団から3人FA移籍した → その球団は1.5位を**3枠**持つ。
  - Bランクも同じ（Bランク1人につき2.5位1枠）。
- 指名は1位と同じく**全球団が同時に**行い、重複したら**公平な抽選**で決める。
- **同じ球団が複数の枠で同じ選手を指名してよい**。
  - 抽選では**1枠を1本のくじ**として数える。当選確率 ＝ その球団がその選手に使った枠の数 ÷ その選手への指名の総数。
  - 例: 球団Xが3枠、球団Yが1枠で同じ選手を指名 → Xの当選確率は3/4、Yは1/4。
- **複数の枠を1人に重ねて当選した場合は、その1人を獲得して終了**。重ねた残りの枠は消え、再指名はしない。
  - 例: 3枠を1人に使って当選 → 獲得は1人だけ。残り2枠は消える。
  - 確率を上げる代わりに枠を手放す、というトレードオフになる。
- 抽選に外れた場合は、**外れ1位と同じように再指名**する。複数の枠を重ねて外れた場合は、**重ねた枠の数だけ**再指名できる。
  - 例: 3枠を1人に重ねて外れた → 3枠とも再指名に回る。
  - 外れても枠は減らないが、その間に他球団が残りの有力な選手を指名しているので、再指名で選べる選手の質は下がる。これが重ねることの代償になる。
- 年俸ランクは**リーグ全体の年俸順位**で決める（球団内の順位ではない）。現実のNPB（球団内で A＝3位以内、B＝4〜10位、C＝11位以下）を12倍にして集約する。

| 年俸ランク | リーグ全体の年俸順位（日本人選手のみ。外国人は除く） |
|---|---|
| A | 1〜36位 |
| B | 37〜120位 |
| C | 121位以下 |
- 人的補償は**ない**。
- ランクの境目、指名権の巡目、金銭の割合は仮。

### 2.4 提携選手のFA年数
- 提携枠で在籍した期間も、FA年数（`faService`）に**数える**。
- 日本に残留すると外国人枠に入るが、提携期間が数えられている分、外国人枠でなくなるまでが短い。

## 3. ポスティング・海外FA・提携枠

### 3.1 ポスティング
- NPBによる審査は**ない**。可否は所属球団が決める。
- 元の球団が得るもの: **譲渡金＋提携枠1つ**。

### 3.2 海外FA
- 元の球団が得るもの: **提携枠1つ**のみ。

### 3.3 提携枠
| 項目 | 決定内容 |
|---|---|
| 得る条件 | ポスティング・海外FAで選手が流出した球団だけ（流出1人につき1枠） |
| 外国人枠との関係 | **別枠** |
| 候補 | 流出した選手を**獲得したMLB球団**が出すプロスペクトのリスト |
| 候補の質 | 流出した選手の価値（能力・契約額）に**釣り合わせる** |
| 期間 | **3〜5年**。選手と日本球団の交渉で決める |
| 所属 | MLB球団のまま（期限付き移籍）。期間が終われば基本は返す |
| 枠の寿命 | 期間が終われば**消える**（埋め直しはできない） |
| 期間後の選択 | 選手の意思で NPB残留・KBO・CPBL・メキシカンリーグ・MLB他球団への移籍も可 |
| NPB残留時 | 借りていた球団に**優先交渉権**。残留すれば外国人枠に入る |

- MLB球団側の損は気にしない。プロスペクトを失いたくない球団は日本人選手を獲らなければよい、という扱い。
- 受け入れの交渉（選手が期間を受けるか）は、出場機会・年俸・期間で受諾率を変える（仮）。

## 4. トレード

- 選手・指名権・金銭・権利を**組み合わせて**取引できる。
  - 例: 4番打者 ⇔ 若手2人＋2位指名権＋5000万
- 1対多（最大1対4）、**最大4球団**の多角トレードも可。
- **CPUの評価**:
  - すべてを同じ「価値」の尺度に換算して合計を比べる。
  - 価値は球団の方針で変える。優勝を狙う球団は即戦力を高く、再建中の球団は若手と指名権を高く評価する。これで両方が得をする取引が成立する。
- プレイヤーが CPU の弱点を突きすぎないよう、同じ球団との連続トレードや極端な不均衡の取引に制限を設ける（仮）。
- 要決定: 補償で得た1.5位・2.5位の指名権と提携枠をトレードできるか。

## 5. 現役ドラフト

- 球団が対象者を選ぶ方式ではなく、**一定の条件を満たした選手が自動的に対象**になる。
- **育成選手は対象外**。
- 条件（在籍年数・1軍出場の少なさなど）は仮。

## 6. 育成選手

### 6.1 育成テンダー
- 育成選手として**通算3年**、支配下に上がれなかった選手は、その年のオフに**自動で育成テンダー対象**になる。
  - 「連続」ではなく「通算」。支配下に一瞬上げて戻す抜け道を防ぐ。
  - いまの `Player.ikuseiYears`（3年で満了）を使う。満了時の扱いをテンダーに置き換える。
- 流れ:
  1. 他球団が支配下契約を提示する。
  2. 複数の球団が提示したら、選手が**条件を総合的に評価**して選ぶ（年俸だけでなく、1.3の要素も含める）。
  3. 元の球団は「同じ契約内容で支配下に上げる」こともできるが、**最終的には選手が総合評価で選ぶ**（元の球団に優先権はない）。
  4. 他球団に移ったら、元の球団に**少額の金銭補償**。
- 誰も提示しなかった場合の扱いは要決定。

### 6.2 育成選手の人数上限
- 上限 ＝ **設備レベルで決まる基本枠 ＋ 育成担当コーチ1人あたり○人**（数値は仮）。
- 設備のレベルは下がらない。上限を超えるのはコーチが辞めたときだけ。

## 7. コーチ（育成担当）

いまの TAB2026 はコーチが**役職ごとに1人**で、人数という考え方がない。次のように変える。

### 7.1 新しい役職
- `CoachEngine.roles2G` に **3軍打撃・3軍投手・3軍守備走塁** を足す。
- この3役職だけ**複数人を雇える**。他の役職はいまのまま1人ずつ。
- 育成選手（3軍）の練習は3軍のコーチが担当する（いまは2軍のコーチが見ている）。

### 7.2 負荷と育成率
- 負荷 ＝ 育成選手の人数 ÷ 育成担当コーチが担当できる人数。
- `practiceMultiplier` の結果に、負荷による係数をかける。

| 負荷 | 係数（仮） |
|---|---|
| 100%超（上限超過） | ペナルティ。超えた人数が多いほど下げる（例: ×0.8） |
| 80%超〜100% | ×1.0 |
| 60%超〜80% | ×1.05 |
| 60%以下 | ×1.08 |

- 余裕が増えるほど上がり幅を小さくする（お金で育成率を上げ続けられないように）。
- いまの 0.6〜1.8 の制限の内側で効かせる。
- 指導力はいまの式がそのまま効くので、「能力の高いコーチを少数」か「普通のコーチを多め」かの選択になる。

### 7.3 3軍監督の育成眼
- いまは育成眼の補正（×0.85〜1.15、練習メニューの選び方）が2軍監督の分しかない。
- 育成選手には**3軍監督の育成眼**が効くように分ける。

### 7.4 シーズン途中の招聘
- コーチはシーズン途中でもすぐ招聘できる。
- ただし年俸が**割高**になる（倍率は仮）。

## 9. 次に考えること

1. **CPU球団の方針**（最優先）: 「優勝を狙う／中間／再建中」を持たせ、成績や戦力の年齢で切り替える。トレードの評価、FAの獲得、ポスティングの許可、提携選手の受け入れがすべてこれを軸に動く。
2. **長期の検証**: `tool/balance_sim.dart` で CPU だけで10〜20年回し、次を確かめる。
   - 1年あたりの FA移籍・トレード・ポスティングの件数
   - 優勝が特定の球団に偏っていないか
   - 育成選手の人数、テンダーで動いた人数
3. **契約まわり**: 契約更改・複数年契約（`player_growth_finance_spec.md` 9章で「予定」のまま）。補償ランクが年俸で決まるので、年俸の決まり方が補償の重さに直結する。
4. **戦力外・引退・トライアウト**: 支配下70人からあふれた選手、テンダーで行き場がなかった選手の受け皿。
5. **外国人選手の獲得**: 提携枠以外の通常の獲得（スカウト、契約相場、外国人枠の人数）。
