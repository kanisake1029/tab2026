## 1. スタミナと体力の違い

| | スタミナ（既存） | 体力（新規） |
|---|---|---|
| 時間の単位 | 1試合 | シーズン |
| 例 | 5回途中でバテて制球が乱れる | 9月にバテる |
| 決まり方 | 能力値スタミナと、その試合の消費量 | 体力（最大値）と回復力 |
| 影響 | 試合中の球速・キレ・制球の低下、降板 | 能力の低下、怪我のしやすさ、起用の可否 |

### スタミナ消費1.5倍（実装済み）
- 1球あたりのスタミナ消費は1.0。
- その半イニングで安打・四球・失点を許した後は、1球1.5になる。倍率は重ねがけしない。
- 平均するとおよそ1.2倍になるため、スタミナの上限も ×1.2 に広げてある（`MatchSimulator.staminaLimit`）。
  - 打たれずに抑えると長く投げられ、打ち込まれると早くバテる。

## 2. 体力（最大値 1〜1000 ＋ 現在値）

- 表記は「体力 290/930 S 93」の形にする（現在値/最大値、ランク、最大値÷10）。

> **実装済み**（`lib/engine/condition_engine.dart`）。下の数値は実装値。

**消費**
- 投手：投げた球数に比例する。先発・中継ぎの役割で差は付けない。
  - 1球 −4（100球で −400）。
  - スタミナ消費1.5倍は体力には掛けない。
- 野手：1試合ごとの定額。
  - −60。捕手は −85、DH は −40、途中出場は −30。

**回復**
- 毎日、回復力だけで決まる量を足す：30 + 回復力 × 0.6（回復力50なら +60/日）。移動日も回復する。
- 1シーズンの検証（`tool/season_condition_test.dart`）：
  - 4人ローテの先発は、4月以降の体力が4割前後で、9月には3割を切る。
  - 6人ローテの先発は、7〜8割を保つ。
  - スタメンは9月に8割弱まで下がる。
  - 怪我は1球団あたり年14件ほど、離脱者はリーグ全体で常に15〜20人。
- 目安：回復力50の先発は、6人ローテ（中5日）でおおむね戻る。4人ローテでは戻りきらず、少しずつ減っていく。
  - 実際の係数は、先発ローテ人数（4〜7）と組み合わせてシミュレーションで決める。

**影響**（現在値 ÷ 最大値で判定）

| 体力の割合 | 能力補正 | 怪我率 | その他 |
|---|---|---|---|
| 50%以上 | 0 | ×1 | |
| 30〜50% | −3 | ×1.5 | |
| 30%未満 | −8 | ×3 | CPU は起用しない（投手） |

## 3. 回復力・怪我しにくさ（1〜100）

- 回復力：体力の毎日の回復量だけを決める。
- 怪我の判定は1試合ごとに行う。
  - 確率 = 0.05% × 体力割合による倍率 × (1.5 − 怪我しにくさ / 100)。
- 怪我の表（例）

| 程度 | 例 | 全治 | 扱い |
|---|---|---|---|
| 軽度 | 軽度の肩痛、打撲 | 3〜10日 | 抹消しない。強行出場できるが、能力 −5 で悪化しやすい（悪化すると全治が延び、程度が上がる） |
| 中度 | 肉離れ、捻挫 | 2〜6週 | 出場不可。自動で抹消し、警告を出す |
| 重度 | 骨折、靭帯損傷 | 2〜6か月 | 出場不可。自動で抹消する |

## 4. 調子（5段階）

- 調子 = 2.5 × sin(t·x + φ) を0の方向へ丸めた整数。
  - 正の値は切り捨て、負の値は切り上げる。
  - x はシーズン開始からの日数。t と φ は選手ごとに違う。
  - t の例：2π/40〜2π/10（周期10〜40日）。

| 値 | −2 | −1 | 0 | +1 | +2 |
|---|---|---|---|---|---|
| 表示 | 絶不調 | 不調 | 普通 | 好調 | 絶好調 |
| sin の範囲 | ≤ −0.8 | −0.8〜−0.4 | −0.4〜0.4 | 0.4〜0.8 | ≥ 0.8 |
| 能力補正（案） | −6 | −3 | 0 | +3 | +6 |

- 「普通」が最も長く続き、山と谷が周期的に来る。
- 期待値をゼロに揃えることはしない。打線全体が好調、といった偏りも起きてよい。
  - 必要ならチーム共通の波を小さく足す。
- モチベーションで振幅の 2.5 を少し増減させる。案：2.5 × (0.8 + モチベーション / 250)。
- 実装済み：`Player.conditionOn(day)`。表示は選手詳細。

## 5. モチベーション（0〜100）

- 変動の原因（案）

| 出来事 | 変化 |
|---|---|
| 試合で打てない（4打数0安打など）、打ち込まれる | −2〜−5 |
| 活躍（猛打賞・好投） | +2〜+5 |
| 怪我 | −10 |
| チームメイト・監督とのイベント（今後） | ±5〜±20 |

- 影響
  - 調子の振幅（4章）。
  - 成長量の倍率：0.8 + モチベーション / 250（0.8〜1.2）。

## 6. 監督への信頼（1〜100）

- 変動の原因（案）

| 出来事 | 変化 |
|---|---|
| 起用し続ける（スタメン固定・勝ちパターンで起用） | 少しずつ + |
| 打てないとすぐ交代させる、短期間で降格させる | − |
| 采配がうまくいった、失敗した | ± |
| イベント（今後） | ± |

- 影響（采配との連動）
  - 実行率 = 70% + 信頼 × 0.5%（信頼30 → 85%、信頼60 → 100%）。
    - 実行されなかった場合は、作戦なしで打席を進める（例：「バントのサインを見落とした」）。
  - 成功率の補正 = (信頼 − 50) × 0.1%（信頼100で +5%）。バント・盗塁・エンドランなどに足す。

## 7. 育成・成長と衰退

**成長タイプとピーク年齢**

| 成長タイプ | ピーク年齢 |
|---|---|
| 早熟 | 23〜27歳 |
| 普通 | 26〜30歳 |
| 晩成 | 29〜33歳 |

- 潜在能力（隠しの値）：能力ごとの上限。今後項目を追加する。

**年間の成長量**
- 年間の成長量 = 年齢カーブ × (出場経験 + 練習指示) × モチベーション倍率。
- 練習指示は既存の `practiceInstruction` を使う（ミート重視・球速アップなど）。指定した能力に重点を置く。
- 年齢カーブ（案）

| ピークとの関係 | 1年あたりの変化 |
|---|---|
| ピーク前 | +2〜+6 |
| ピーク | ±1 |
| ピーク後 | −1〜−4 |
| ピークから5年以上後 | −3〜−6 |

**衰え方の順番**（ピーク後）
1. 球速・走力が先に落ちる。
2. パワー・肩・スタミナが次に落ちる。
3. ミート・選球眼・制球は最後まで残る。

## 8. オフシーズン処理（新設予定）

現状のアプリにはシーズンの切り替えが無い。日本シリーズの後に、次の順で処理する。

1. 年齢とプロ年数を +1。生年月日は固定。
2. 成長と衰退を反映（7章）。
3. 契約更改（9章）。
4. 引退と戦力外。
   - 引退の目安：35歳以上で OVR が低い、など。
   - 戦力外の目安：支配下70人を超えた分を、下位から外す。
5. 新人の加入（ドラフトは将来。当面は自動生成）。
6. 体力と怪我をリセットし、日程を作り直す。

## 9. 年俸・球団経営

**年俸の初期値**（実装済み：`lib/utils/salary_utils.dart` の `estimateSalary`）
- 基準：800万 × 10^(0.05 × (OVR − 50))。OVR50 → 800万、60 → 2530万、70 → 8000万、80 → 2.5億。
- 補正

| 条件 | 倍率 |
|---|---|
| プロ1年目 | ×0.5（上限1600万） |
| プロ2年目 | ×0.65 |
| プロ3年目 | ×0.8 |
| 外国人 | ×1.5 |
| 27〜32歳 | ×1.1 |

- 下限は440万、10万円単位。
- 固有12の結果：1球団の総額はおよそ27億〜39億円。中央値3570万、最高2.8億。
- 選手詳細では手動で変更でき、「自動算出」ボタンで式の値に戻せる。

**契約更改**（予定）
- 成績を数値化して増減率を決める（案：WAR に近い指標から −25%〜+100%）。
- 減額制限（1億円以下は25%、1億円超は40%）を超える提示は選手が拒否できる。拒否されたら自由契約。
- 複数年契約は `contractYears` で表す。満了までは更改しない。

**球団の収支**（予定）

| 区分 | 内容 | 決まり方（案） |
|---|---|---|
| 収入 | 観客動員 × 客単価 | 観客動員 = 球場の収容人数 × (0.6 + 人気 × 0.3 + 勝率補正) |
| 収入 | 放映権 | 固定額 + 人気に応じた額 |
| 収入 | グッズ | スター選手の人気に応じた額 |
| 支出 | 年俸総額 | 全選手の `salary` の合計 |
| 支出 | 運営費 | 固定額 |

- 球団の資金が予算を下回ると、補強（FA・トレード・外国人の獲得）に制限をかける。

**画面案**
- 選手一覧：年俸と年俸総額を表示する（実装済み）。
- ホーム：球団の資金と今季の収支。
- オフ：契約更改の画面（提示額と、選手の反応）。

## 10. バランス確認の方針

- 調子・体力の補正を入れた後も、OVR65 同士の基準が保たれていることを `balance_sim` で確認する。
  - 基準：得点 ≈ 4.0、打率 ≈ .250、本塁打 ≈ 0.83。
- 先発ローテ人数（4〜7）と体力の関係をシミュレーションで確かめる。
  - 4人ローテでは9月ごろに先発が疲れていること。
  - 6人ローテでは、ほぼ疲れが残らないこと。
- 怪我人の数の目安：1球団で同時に2〜4人程度。
